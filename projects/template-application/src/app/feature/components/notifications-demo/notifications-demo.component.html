Notifications

Inline notifications, callouts, and toasts from the component library. Toasts appear at the top-right and feed the notification bell in the header.

Inline notifications

Embedded in the page flow to report the outcome of an action or surface a persistent condition. The success example is dismissible and includes an action.

@if (inlineVisible()) { } @else { }

Callouts

Static, non-dismissible context blocks for informational or cautionary notes.

Toasts

Transient messages dispatched via ToastService. They stack at the top-right (max 5) and increment the header notification bell. With auto-dismiss off they remain until cleared.
